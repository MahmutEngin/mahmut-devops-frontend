4. Nginx Reverse Proxy ve SSL Konfigürasyonu

Let's Encrypt Certbot ile her iki alt alan adı için SSL sertifikası tanımlanmış, HTTP (80) istekleri otomatik olarak HTTPS (443) protokolüne yönlendirilmiştir.

Backend Reverse Proxy Blok Örneği

server {
    server_name mahmut-backend.team-vit-devops.nl;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    listen 443 ssl;
    ssl_certificate /etc/letsencrypt/live/mahmut-frontend.team-vit-devops.nl/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/mahmut-frontend.team-vit-devops.nl/privkey.pem;
}

6. CI/CD Pipeline & GitHub Workflows

GitHub Actions otomasyonu ile main branch'ine yapılan her push sonrasında kodlar sunucuda otomatik olarak build edilip canlıya alınmaktadır.

Frontend Workflow (.github/workflows/deploy.yml)

name: Deploy Frontend
on:
  push:
    branches: [ main ]
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: npm ci || npm install
      - run: npm run build
      - uses: appleboy/ssh-action@v1.0.3
        with:
          host: ${{ secrets.SERVER_HOST }}
          username: ${{ secrets.SERVER_USER }}
          key: ${{ secrets.SERVER_SSH_KEY }}
          script: |
            cd ${{ secrets.DEPLOY_PATH }}
            git pull origin main
            npm install
            npm run build
            sudo nginx -t
            sudo nginx -s reload

7. Güvenlik Prensipleri ve Best Practices

  • Port İzolasyonu: Node.js portu (3000) dış dünyaya kapatılmış, yalnızca Nginx Reverse Proxy üzerinden erişim sağlanmıştır.
  • Hassas Veri Yönetimi: .env dosyaları repolara dahil edilmemiş, bağlantı bilgileri GitHub Secrets üzerinden yönetilmiştir.
  • Nginx Syntax Check: CI/CD sürecinde sudo nginx -t ile sözdizimi doğrulanmadan reload yapılmaz.
