3. Proje Mimarisi ve Teknoloji Özeti

Proje, bağımsız iki Docker container'ının Dokploy orkestrasyonu altında çalıştırılması esasına dayanır:

  • Frontend (React + Vite): Multi-stage Dockerfile ile derlenmiş, production aşamasında hafif bir Nginx:Alpine container'ı üzerinden static web sunumu sağlamaktadır. Container içi port 80'dir.
  • Backend (Node.js + Express): REST API mimarisinde geliştirilmiş, sağlık kontrolü (/api/health) ve sistem bilgisi (/api/info) sunan servistir. Container içi port 3000'dir.
  • Trafik Yönlendirme (Traefik): VPS üzerindeki tüm 80 ve 443 portu trafiği Traefik reverse proxy tarafından karşılanır. Domain bazlı SSL otomasyonu Let's Encrypt entegrasyonu ile yürütülmektedir.
  • CI/CD Otomasyonu: GitHub App & Webhook entegrasyonu ile main branch'ine atılan her git push işlemi Dokploy üzerinde otomatik rebuild ve redeploy akışını başlatır.
